MediaToolkit.NET 0.3.1 - fixes to the GStreamer and mpv transcoders.

Both could accept an audio request, report success, and write something other
than what was asked. Everything a request says now either reaches the file or
is reported: as an error before anything is written, or as a warning in
TranscodeResult.Warnings. No public API changed.

Found by generating 220 Matroska audio files over eleven formats through each
backend and reading every one back with the FFmpeg prober. FFmpeg made all 220
as asked; GStreamer went from 121 to 193 and mpv from 86 to 175, the rest being
refused or warned with the reason.

FIXED - GSTREAMER

- ChannelMask was passed to channel-mask unchanged, but FFmpeg and GStreamer
  number speakers differently from the side pair on, so 7.1 and the side
  layouts failed. The mask is now translated.
- DTS (avenc_dca) and RealAudio 1.0 (avenc_real_144) are encoded.
- 24-bit PCM is written raw as S24LE.
- 24-bit FLAC (SampleFormat.S32) is fed to flacenc as S24_32LE.
- A planar sample format pins the width alone; libav's elements and
  matroskamux are interleaved only.
- lamemp3enc no longer halves the rate at low bit rates.
- avenc_mp2 is preferred to twolamemp2enc, which refuses valid bit rates such
  as 320 kbit/s mono.
- TrueHD is refused up front: no GStreamer muxer takes it.

FIXED - MPV

- Channels, sample rate and sample format are passed on (--audio-channels,
  --audio-samplerate, --audio-format); they were ignored and the input's kept.
- TrueHD and MLP in Matroska are refused: mpv's timestamps made them run 20%
  long.
- PCM output warns that mpv pads the end with up to 16384 samples of silence.
- The output check uses the FFmpeg prober when available; mpv cannot read
  RealAudio in Matroska.

VERIFIED BY RUNNING

- Debian 13, FFmpeg 7.1.5, GStreamer 1.26.2, libmpv 2.5: 206 unit and 93
  integration tests pass.
- Windows 11: unit, FFmpeg and mpv integration tests pass.

KNOWN LIMITATIONS ADDED

- GStreamer ignores a variable AAC quality, with a warning: gst-libav does not
  expose libavcodec's qscale flag.
- TrueHD: not on GStreamer, not in Matroska on mpv. Use FFmpeg.
